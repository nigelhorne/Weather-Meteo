 1002: =head1 LIMITATIONS
 1003: 
 1004: =over 4
 1005: 
 1006: =item * Archive data lag
 1007: 
 1008: The Open-Meteo archive endpoint has a lag of approximately five days before
 1009: recent historical data becomes available.
 1010: For dates within the past five days,
 1011: C<weather()> may return C<undef> even when no error occurs.
 1012: Use C<forecast()> or C<sunrise_sunset()> (without a date) to obtain data for
 1013: today or recent days.
 1014: 
 1015: =item * Coordinate range

  Mutants (Total: 2, Killed: 2, Survived: 0)
 1016: 
 1017: The module normalises coordinates with a bare leading decimal point (e.g.
 1018: C<".5"> to C<"0.5">) but does not validate that latitude is within C<-90..90>
 1019: or longitude within C<-180..180>.
 1020: Out-of-range values are passed to the API, which may return an error.
 1021: 
 1022: =item * No sub-hourly resolution
 1023: 
 1024: The hourly data arrays always contain exactly 24 entries per day (one per hour).
 1025: Sub-hourly resolution is not supported by this interface.
 1026: 
 1027: =item * Per-process rate limiting
 1028: 
 1029: The C<min_interval> rate limiter tracks the last request timestamp within a
 1030: single process instance.
 1031: Multiple concurrent processes or threads are not coordinated and may collectively
 1032: exceed the desired request rate.
 1033: 
 1034: =item * Timezone resolution requires an API key
 1035: 
 1036: Automatic per-location timezone resolution requires setting the
 1037: C<TIMEZONEDB_KEY> environment variable to a valid key from
 1038: L<https://timezonedb.com>.
 1039: Without it the module defaults to C<Europe/London> for all locations.
 1040: 
 1041: =item * No list-context support
 1042: 
 1043: C<weather()> and C<forecast()> enforce scalar/hashref context via
 1044: L<Return::Set>.
 1045: List context is not currently supported.
 1046: 
 1047: =item * Access control by convention only
 1048: 
 1049: Private methods (prefixed with C<_>) are not enforced by a module such as
 1050: L<Sub::Private>.
 1051: Callers are expected to treat them as internal; white-box test files may
 1052: access them directly.
 1053: 
 1054: =item * Host parameter restricted to plain DNS hostnames
 1055: 
 1056: The C<host> constructor parameter (and the C<WEATHER__METEO__host> environment
 1057: variable) must match C</\A[A-Za-z0-9][A-Za-z0-9.\-]*(:\d{1,5})?\z/>.
 1058: IP addresses in CIDR notation, URLs with path components, C<@>-style
 1059: user-info, and other special characters are rejected with a C<croak> to
 1060: prevent Server-Side Request Forgery.
 1061: If you need to test against a local service on a non-standard port, use a
 1062: plain C<hostname:port> string (e.g. C<localhost:8080>).
 1063: 
 1064: =item * Coordinate values limited to decimal numbers
 1065: 
 1066: Latitude and longitude must match C</\A-?(?>\d+)(?:\.(?>\d+))?\z/> after
 1067: leading-decimal normalisation.
 1068: Exponential notation (C<1.5e2>), hex (C<0x1F>), and strings with embedded
 1069: whitespace are rejected.
 1070: Pass a pre-formatted decimal string rather than a Perl numeric expression if
 1071: your caller might produce non-decimal representations.
