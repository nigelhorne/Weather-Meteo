 1420: Every failure of C<weather()>, C<forecast()> and C<sunrise_sunset()> that is not
 1421: a usage error comes back as C<undef> with a C<carp>.
 1422: A caller therefore cannot tell a rate limit from an outage from an unknown
 1423: place without parsing the warning text.
 1424: This is the documented contract, kept for compatibility, but an exception
 1425: class (or at least a C<last_error()> accessor) would be a better design.
 1426: 
 1427: =item * Retries block the caller
 1428: 
 1429: Retrying a transient failure sleeps in the calling process, for up to
 1430: C<max_retries> times the (doubling, capped) delay: about 7 seconds with the
 1431: defaults.
 1432: Set C<max_retries> to C<0> for a non-blocking client, or do the retrying
 1433: yourself.
 1434: 
 1435: =item * Messages are translatable, but the plural rules are not
 1436: 
 1437: L</i18n> understands C<one> and C<other> only, which is right for English,
 1438: German and French but not for languages with several plural forms.
 1439: It also does not translate strings that come from outside the module, such as
 1440: the text of an HTTP status line or an exception from the JSON decoder.
 1441: 
 1442: =item * Dates are checked by shape, not by calendar
 1443: 
 1444: C<2022-02-31> and C<2022-13-45> have the shape C<YYYY-MM-DD> and are passed to
 1445: the API, which rejects them.
 1446: The module does not check them itself because no calendar module is a
 1447: dependency.
 1448: 
 1449: =item * "Today" is the host's date, not the location's
 1450: 
 1451: When C<sunrise_sunset()> is called without a date, or with today's date, "today"
 1452: is taken from the local clock of the machine running the code, not from the
 1453: C<tz> requested.
 1454: Near midnight and for distant time zones that can be a day out.
 1455: 
 1456: =item * Cache keys use the text of the coordinates
 1457: 
 1458: C<51.34> and C<51.340> are cached separately, and so are C<tz> spellings that
 1459: the API treats as the same zone.
 1460: The results are correct; only the hit rate suffers.
 1461: 
 1462: =item * Host parameter restricted to plain DNS hostnames
 1463: 
 1464: The C<host> constructor parameter (and the C<WEATHER__METEO__host> environment
 1465: variable) must match C</\A[A-Za-z0-9][A-Za-z0-9.\-]*(:\d{1,5})?\z/>.
 1466: IP addresses in CIDR notation, URLs with path components, C<@>-style
 1467: user-info, and other special characters are rejected with a C<croak> to
 1468: prevent Server-Side Request Forgery.
 1469: If you need to test against a local service on a non-standard port, use a
 1470: plain C<hostname:port> string (e.g. C<localhost:8080>).
 1471: 
 1472: =item * Coordinate values limited to decimal numbers
 1473: 
 1474: Latitude and longitude must match C</\A-?(?>\d+)(?:\.(?>\d+))?\z/> after
 1475: leading-decimal normalisation.
 1476: Exponential notation (C<1.5e2>), hex (C<0x1F>), and strings with embedded
 1477: whitespace are rejected.
 1478: Pass a pre-formatted decimal string rather than a Perl numeric expression if
 1479: your caller might produce non-decimal representations.
 1480:
